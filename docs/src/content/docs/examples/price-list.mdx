## What to notice

- The SKU field has declarative checks (`required`, `unique`, `pattern`) and a code check beside them. The code check runs for every SKU typed, and never for an empty cell, which `required` covers.
- `onChange` writes with `ctx.set`, and its writes are part of the same undo step as the SKU that caused them.
- `formula: 'forbid'` on the price and `'require'` on the price with tax keep calculated columns calculated.
