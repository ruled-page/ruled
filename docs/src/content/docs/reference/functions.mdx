Formulas are calculated by the editor's own engine, in its worker, as cells change. Dynamic arrays spill as in Excel 365, and `LET`, `LAMBDA` and its helpers (`MAP`, `REDUCE`, `SCAN`, `BYROW`, `BYCOL`, `MAKEARRAY`) work, as do names defined with them. On opening, the engine's results are compared with the values Excel saved, and any that disagree are reported.
